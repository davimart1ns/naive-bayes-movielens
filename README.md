#  Naive Bayes: Do Zero à Prática

Notebook de consulta rápida cobrindo a teoria, implementação manual e aplicação prática do algoritmo **Naive Bayes**.

## 📑 Conteúdo
* **Teoria:** Teorema de Bayes, Suavização de Laplace (*Laplace Smoothing*) e `BernoulliNB` vs `MultinomialNB`.
* **Prática:** Implementação manual (*from scratch*) e com `scikit-learn` no dataset **MovieLens 1M**.
* **Métricas:** Matriz de Confusão, Precision, Recall, F1-Score e Curva ROC/AUC.

---
**Fonte de estudo:** *Machine Learning com Python na Prática* — Yuxi (Hayden) Liu.
